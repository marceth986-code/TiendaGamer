# TiendaGamer

TiendaGamer es un proyecto de una tienda online de productos y componentes para PC.

El programa permite administrar los productos de la tienda mediante un menú y guardar la información en un archivo JSON.

## Funciones

El programa permite:

- Mostrar todos los productos.
- Agregar nuevos productos.
- Buscar productos por nombre.
- Modificar productos.
- Eliminar productos.
- Ordenar productos por diferentes criterios.
- Filtrar productos por categoría.
- Guardar los cambios realizados.

## Productos

Cada producto contiene:

- ID
- Nombre
- Categoría
- Precio
- Stock

Algunos ejemplos de categorías son:

- Placa de video
- Procesador
- Memoria RAM
- Motherboard
- Almacenamiento
- Fuente
- Gabinete
